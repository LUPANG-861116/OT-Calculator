# 🚒 消防超勤加班費印領清冊轉換器 (Chaoqin Converter)

一鍵將外勤消防人員輪休表（休宿表）排班符號，精準換算為每日服勤工時，並自動回填至局頒標準「超勤加班費申請及印領清冊」的純前端 Web 應用工具。

---

## ✨ 核心特色與亮點

- **🔒 100% 純前端離線運算（資安第一）**：
  所有工時換算與 Excel 文件處理均在瀏覽器本機記憶體中完成，**同仁姓名、官職等、請假、帳號及薪資資料絕不上傳外部伺服器**，符合政府嚴格之公務個資保護規範。
- **⏱️ 三種作業模式自由切換**：
  1. **空白表填入**：上傳空白清冊，系統直接帶入服勤工時並精準計算超勤時數與金額。
  2. **檢核標示差異**：維持原檔數值不動，將與輪休表不符處以醒目紅框標示，檢核省時省力。
  3. **強制覆蓋重填**：無論原檔是否已填寫，一律以輪休表最新狀態強制覆蓋更新。
- **📅 智慧辨識大小月份與公務工時**：
  自動計算小月（17天本休）與大月（18天本休），支援動態公務工時基準（160hr / 168hr），並內建一鍵下載對應月份動態空白清冊功能。
- **⚖️ 複雜假別法規智能解析**：
  - **連續公假折算**：完整支援跨週末之連續公假認定，精準判定應扣減之本休天數。
  - **回補假別判定**：身心調適假、喪假、產假/陪產假等依請假規則判定回補 8 小時機制。
  - **彈性休息時間**：自動解析如 `08-14 彈`、`14-18 彈` 等多樣化休息區間並回填服勤時數。
- **🏷️ 自動機關與分隊辨識命名**：
  自動跨表掃描單位名稱，匯出檔名全自動符合公文標準規範：  
  `新北市政府消防局【OO分隊】【OOO年OO月份】超勤加班費申請及印領清冊.xlsx`。

---

## 🚀 部署與線上使用

本專案為靜態單頁應用（SPA），可直接託管於 [Vercel](https://vercel.com/)、[GitHub Pages](https://pages.github.com/) 或分隊內部伺服器 / NAS。

- **線上網址**：部署於 Vercel 後即可點擊開啟。
- **離線單檔**：雙擊開啟 `超勤格轉換器.html` 即可離線秒開使用。
